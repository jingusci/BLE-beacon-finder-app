## Cambios respecto a la version anterior
- Se rediseño la pantalla de balizas conocidas para mejorar contraste, jerarquia visual y legibilidad.
- La lista de balizas paso de un texto plano a tarjetas con mejor separacion entre nombre, UUID y audio asociado.
- Se mejoro el bloque superior de la pantalla con instrucciones mas claras sobre como editar y borrar balizas.
- El dialogo de alta y edicion se actualizo con campos outlined, ayuda visual para el UUID y mejor consistencia con el estilo general de la app.
- Ahora cada baliza existente puede borrarse directamente desde la ventana de edicion, sin depender solo del toque prolongado.
- El flujo de borrado tambien permite eliminar balizas que originalmente venian cargadas por defecto.
